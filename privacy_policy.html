개인정보처리방침

하루 한 장 (HaruLabs) · 시행일: 2026년 6월 1일

HaruLabs(이하 "개발자")가 제공하는 Android 앱 하루 한 장(이하 "앱")은 사용자의 프라이버시를 최우선으로 설계되었습니다. 본 방침은 앱이 수집하거나 처리하는 정보, 그 목적 및 사용자의 권리를 안내합니다.

📌 핵심 요약: 모든 사진과 일기 데이터는 사용자의 기기 안에만 저장됩니다. 외부 서버로 전송되지 않으며, 계정 생성이나 클라우드 동기화는 없습니다.

1. 수집하는 정보 및 목적

① 사진 및 일기 데이터

  • 사용자가 직접 촬영하거나 갤러리에서 선택한 사진, 메모, 날짜, 감정 이모지
  • 모든 데이터는 기기 내부 저장소에만 저장되며, 개발자 또는 제3자 서버로 전송되지 않습니다.

② 위치 정보

  • 일기 저장 시 자동 날씨 태깅 및 지도 기능을 위해 현재 위치(GPS/네트워크)를 일시적으로 사용합니다.
  • 위치 정보는 기기 내에서만 처리되며, 날씨 API 호출 시 좌표만 전송되고 사용자 식별 정보는 포함되지 않습니다.
  • 위치 태그가 포함된 일기 데이터는 기기 내부에만 저장됩니다.

③ 카메라

  • 오늘의 사진을 직접 촬영할 때 카메라 권한이 필요합니다.
  • 촬영된 사진은 외부로 전송되지 않으며 기기에만 저장됩니다.

④ 생체 인증 (지문 / 얼굴 인식)

  • 앱 잠금 기능을 위해 Android 생체 인증 API를 사용합니다.
  • 생체 정보(지문, 얼굴 데이터)는 기기의 보안 영역(TEE)에서만 처리되며, 앱은 원시 생체 데이터에 접근하거나 저장하지 않습니다.

⑤ 광고 식별자 (Advertising ID) — Google AdMob

  • 앱은 Google AdMob SDK를 포함합니다. AdMob은 광고 게재 및 측정을 위해 Android 광고 식별자(AAID)를 수집할 수 있습니다.
  • 사용자는 기기 설정 → Google → 광고에서 광고 ID 재설정 또는 광고 맞춤설정 해제를 선택할 수 있습니다.
  • AdMob의 데이터 처리 방식: Google 개인정보처리방침

⑥ ML Kit (기기 내 사진 검색)

  • 사진 검색 기능은 Google ML Kit를 기기 내에서만 실행합니다.
  • 사진 데이터 및 검색 쿼리는 외부 서버로 전송되지 않습니다.

2. 수집하지 않는 정보

  • 이름, 이메일, 전화번호 등 개인 식별 정보
  • 사용자 계정 또는 로그인 정보
  • 사진, 메모, 일기 데이터의 서버 업로드 또는 클라우드 동기화
  • 제3자(광고주 제외)와 공유되는 어떠한 사용자 데이터

3. 요청하는 앱 권한

  • CAMERA — 사진 촬영
  • READ_MEDIA_IMAGES / READ_EXTERNAL_STORAGE — 갤러리에서 사진 선택
  • ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION — 날씨 태깅 및 지도 기능
  • USE_BIOMETRIC / USE_FINGERPRINT — 앱 잠금
  • POST_NOTIFICATIONS — 기록 알림 및 n년 전 오늘 알림
  • INTERNET — 날씨 API 호출, AdMob 광고 로드
  • WRITE_EXTERNAL_STORAGE — ZIP 백업, PDF 포토북 내보내기

각 권한은 해당 기능을 사용할 때만 요청되며, 권한을 거부하더라도 관련 기능을 제외한 나머지 기능은 정상적으로 이용할 수 있습니다.

4. 데이터 보관 및 삭제

모든 데이터는 사용자의 기기에만 저장됩니다. 앱을 삭제하면 기기에 저장된 앱 데이터가 함께 삭제됩니다. 개발자는 사용자 데이터의 사본을 보유하지 않습니다.

5. 아동 개인정보 보호

본 앱은 만 14세 미만 아동을 대상으로 하지 않습니다. 만 14세 미만의 사용자가 앱을 사용하는 경우 보호자의 동의가 필요합니다.

6. 개인정보처리방침 변경

본 방침은 법령 또는 앱 기능 변경에 따라 업데이트될 수 있습니다. 변경 시 앱 내 공지 또는 Google Play 스토어 업데이트 노트를 통해 안내드립니다.
